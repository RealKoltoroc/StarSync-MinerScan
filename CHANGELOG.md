# Changelog

## 0.6.8 - 2026-09-08

Public baseline release.

- Stable DXGI ROI capture for GPU-rendered game output with GDI fallback.
- Embedded local OCR models for a self-contained executable.
- Passive global Numpad controls for scanner/calibration operations.
- Optional fixed LIVE OCR preview tab.
- Compact potential-candidate status in the main scanner view.
- Configurable same-material detection/report cooldown; default 120 seconds.
- Local-first SCUnpacked baseline/update workflow.
- Optional cached enrichment through UEX, Star Citizen Wiki API and StarCitizen.Tools.
- Local refining calculator with preferred refinery, method strategy and editable base-efficiency assumptions.
- Portable single-EXE distribution with runtime data under `%LOCALAPPDATA%\StarSync MinerScan`.
- Orange/charcoal StarSync MinerScan UI and report branding.
